# S021　砺风测风弓

| 字段 | 规格 |
|---|---|
| 装备ID | `S021` |
| 种类 | 特性装备 |
| 槽位 | `MH` |
| 器具类型 | 弓 |
| 固定基础属性 | 生命+400、武力+500；其余属性+0 |
| 正向预算 | 生命400÷400 + 武力500÷100 = 6（T1归一预算；高档先除工艺倍率） |
| 角色限制 | 八族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 武器操作

- 双手，占主手和副手；副手必须空。
- 普攻取值为武力→护甲，P1200，1 AP、0精力，距离2–4的一名可见敌人，直射，受矮掩体修正。使用后占本次主动伤害动作。
- 招牌「穿弦」为1 AP、2精力、CD1。选择同一行列距离2–4的首名可见敌人及其后一格，P1200、直线系数0.75；实墙阻断，友军不受伤。 基础读取武力→护甲，发动标签为武技。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 特性

穿弦可在地图风口正吹方向起手时把最远距离4延到5，P1200降到8，两格贯穿仍按直线0.75；只延指定风向而不弯弹道。

## 用途与应对

依赖风口和站位，逆风或换线无收益。

## 结算约束

本节数值上限按T1显示，战役上限按受益/受击者成长档换算；动作次数不变。

本件只能改变上述明确操作。普通护盾取较高且总上限1600；治疗每目标每轮2400；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计800。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

无风图完全采用原穿弦范围，不获得常驻射程。

## 获得与工坊

完成 `P20` 雪线复信后，雪线工棚的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「制柄、固定工作端并校直→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

## 战役工艺档与竞技

上述人物生命、攻防、威力、治疗和盾以T1显示。T1–T8工艺倍率依次为1/1.25/1.50/1.75/2/2.25/2.50/2.75；固定属性乘本件工艺倍率，明示人物伤害/盾/治疗的定值随装备档成长并受目标档上限约束。HP百分比、机关结构耐久刻度、AP、精力、格数、CD、次数与预算不放大。器械若有战斗HP须用战斗HP字段，不能把结构耐久当人物生命。武器招牌P按人物成长档计算，不再乘第二次装备档。系列额外属性按成员最低工艺档计算。竞技强制T1，特性条件不因成长扩大。详见[数值成长](../../08_成长与构筑/04_战役成长与大数值.md)。
