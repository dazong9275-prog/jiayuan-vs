# 棋盘空间、基础指令与属性计算

本文件补齐可实现的默认空间规则。具体地图可声明地形步耗和机关权限；不能覆盖AP、形态、控制、伤害次数等[统一规则](00_统一规则_先读.md)上限。

## 1. 坐标与占格

格图左上为A1，字母从西向东，数字从北向南。上北、右东、下南、左西。世界模型1格建议1.5米，仅是表现换算；战斗计算始终使用整数格。四向相邻距离1，不允许斜走。层高不改变二维距离，但上下层之间必须有明确坡道或通行边。

1×1单位锚格即其占格。2×2巨体以一格为锚并记录其余三格相对偏移；锚格并非必须左上，变形时须包含原锚格。移动每一步平移整个占格集合，每格均须满足地图通行和碰撞要求。多个被命中格属于同一单位时按UnitId去重。

人物不可结束在另一个人物占格。普通步行可以经过同队1×1人物，但不能在其中停下；不得经过敌人或巨体占格。巨体不能借友军让路忽略自身足迹碰撞。复归免伤且不挡路的单位按复归规则暂时不参与阻挡，但也不能用来压板或持核心。

目标/交互进展只读人物锚格，不能让巨体边角替自己跨线。对人物施术的距离使用施术者锚格到目标最近合法受击格；因此巨体更易被攻击，但自身射程不从任意体格额外伸长。以地面为目标的施术读锚格到所选中心格距离。

## 2. 视线与掩体

地图必须为每个阻挡对象声明 `blocksWalk`、`blocksDirect`、`blocksLob`、`providesCover` 四项；不可仅由外观推断。实墙默认四项为真、真、真、假。矮掩体默认真、假、假、真；某地图声明的雾只遮某类视线。地图有显式值时使用显式值。

视线以格中心射线使用supercover栅格遍历；正好过格角时，两侧接触格都纳入遮挡检查。任何被经过的有效阻挡格截断该段。主动目标可见不等于射线畅通；实墙后已经被队友看到的敌人也不能被直射选中。

直射若穿过紧邻目标的提供掩护边/格，应用0.80位置系数；抛射默认不使用该系数，仍须通过自己的视线检查。角色站在有盖板的地面上不自动获得“掩体后”状态。多处掩体不重复相乘。装备若只忽略遮线而未写忽略掩体，不自动取消减伤。

背刺只由技能卡显式启用：目标朝向的反向半平面，且施术者所在方向与目标背向夹角小于等于45度时成立；恰好侧方不成立。需要格向量时用点积/叉积整数比较，禁止依赖模型眼睛朝向。掩体与背刺并存按统一规则仅取0.80。

## 3. 格形模板

令施术者锚格为O，选定四向单位向量F，右侧垂直向量R。技能射程首先限制指定目标或区域中心；形状扩展可超出该中心射程，但仅包含卡面明确列出的格。区域不得越过实墙传播，逐目标检查中心/施术者至受击格的声明路径。

| 模板 | 确定集合 | 默认伤害系数 |
|---|---|---:|
| 单格 | 所选一个合法格 | 1.00 |
| 前方直线L | O+F至O+L×F；遇墙截断 | 0.75 |
| 前方横排2 | {O+F, O+F+R}或{O+F, O+F−R}，提交时选左/右 | 0.75 |
| 扇形3 | {O+F,O+2F−R,O+2F+R} | 0.75 |
| 2×2区域 | 选中心角与四个偏移，预览固定朝向，不临时多算中心格 | 0.75 |
| 十字5 | 中心C及其四邻，只有明确延时招式可用 | 0.90 |

技能卡有逐格定义时优先使用其定义。泛称扇形不能扩大为九格；没有完整形状参数的技能不通过内容编译。所有形状边界在确认前显示。常规即时人物伤害最多覆盖4格；更大区域先预告。友伤默认关闭，技能或地图若需要例外必须逐目标类别说明，不能由演出粒子决定。

## 4. 基础指令成本表

| 指令 | AP/精力 | 距离与条件 | 次数和结果 |
|---|---|---|---|
| 步行 | 1/0 | 路径步耗总计≤当前移动 | 每激活一次；攻击位移共用 |
| 普攻 | 1/0 | 按主手类型 | 每激活主动伤害共用一次，P1200 |
| 架盾 | 1/0 | 自身 | 每激活一次，800×自身g盾至下次自身激活开始 |
| 开关/阀/压力交互 | 默认1/0 | 地图明确的目标与距离，一般四邻 | 按地图状态机；失败不扣费 |
| 拾取/放下任务物 | 1/0 | 自身格或四邻，按物件权限 | 不复制对象；形态禁竞技核心 |
| 交接核心 | 1/0 | 四邻队友，同意后提交 | 每队每轮一次；不额外奖励接收方AP |
| 递药 | 1/0 | 四邻友方、有携带空位、同意 | 保留瓶ID、使用次数和种类 |
| 饮药 | 1/0 | 自身持有瓶 | 每人每轮一次；瓶消费 |
| 投地药 | 1/0 | 距2合法格 | 与饮药二选一，不能一瓶两用 |
| 解印 | 1/0 | 自身被沉默 | 解后进入两次完整自身激活的保护 |
| 结束激活 | 0/0 | 当前行动者 | 可附带一次四向朝向，未用AP清零 |

机关的每激活重复操作限于其状态机，不能拿无限免费“确认”触发装备。任何附带免费效果都跟随一次已提交的合法根动作；空操作和取消预览不产生战斗事件。

## 5. 属性的用途与例算

下表均为T1（g=1）算例；战役各档按统一规则改变技能P、人物属性和目标防御常数。

生命决定可承受损耗，不自动成为攻击属性；武力、术力分别被卡片读取；护甲、法抗分别对应减伤通道；精力控制连续高阶动作；AP控制同次激活内的机会；移动与射程决定能否兑现数值。首发不再叠加命中、闪避、暴击、攻速、六属性抗性等常驻面板，装备深度放在数值分配和真实条件效果。

| 场景（T1，g=1） | 计算 | 结果 |
|---|---|---:|
| 基础普攻打基础防御 | floor((1200+2000)×10000/12000) | 2666 |
| 同数值直线范围命中一目标 | floor((1200+2000)×10000/12000×0.75) | 2000 |
| 单点直射穿目标掩体 | floor((1200+2000)×10000/12000×0.80) | 2133 |
| P1000治疗、术力2000 | floor(1000+2000×0.30) | 1600，仍受每轮2400限制 |
| 先有1200盾，再获得800盾 | 取较高且保留原时长 | 仍1200，不续期 |
| 武力6000的P1200攻击防御0 | floor((1200+6000)×10000/10000) | 7200，并不保证目标能撑两击 |

放大后保留更细的整数精度，例如旧式26点伤害对应新公式2666而非先取旧整值再乘100。公式相对比例保持，但末位取整差异必须进入回放内容版本，不承诺新旧战斗逐点完全相同。战役Tn采用V2的g计算当前属性、技能P与目标防御分母；不能只放大面板而保留旧常数100。

正预算是一致性约束，不能替代实战平衡。区域优势、一次行动能否兑现、攻击两目标的价值和队友配合都须在地图中验证。

## 6. 自动、被动和选择窗口

自动技能由公开条件触发，备战时设置允许与候选优先级；同一机会按顺序取首个合法且可支付的候选。它与装备反应共享每棋每轮一次。不得因为装备了两个自动技就额外获得两次触发。对手的激活不会弹出长时间等待你选择的窗口。

被动只持续修改自身声明的规则；若一次事件会产生独立伤害、治疗或额外操作，必须归入受限自动/装备事件而非伪装为无次数被动。持续条件修正的计算保持纯函数，无递归触发。

本人激活开始到期的延时攻击可有该卡明确允许的继续/取消选择，例如S166；这占用本人的25秒计时，超时默认继续已承诺动作。准备与到期激活均预留一次伤害动作，打断或主动弃咏不释放到期预留。角色倒地时取消效果，但消耗与时间账本按统一规则处理。

## 7. 结构刻度与人物生命分离

`StructureIntegrity`是机关可操作次数的刻度，例如铜枢耐久2、一次斧击扣1。它不随100倍显示单位或T档增长。只有卡片明确的结构损坏/修复操作才改变刻度；普通攻击只有在对象声明“每次合法主伤害命令扣1结构耐久”时才能拆除。人物伤害不得直接减结构刻度，否则一个普通攻击会错误摧毁整段谜题。

使用战斗生命的可召唤单位另填`CombatHP`，按人物量级计算伤害与护盾。一个对象不能在同一条结算中同时按HP和StructureIntegrity受损。对机关选目标必须先切换物件模式，不同时免费命中旁边人物。生命归零与机关状态迁移是两类不同事件。
