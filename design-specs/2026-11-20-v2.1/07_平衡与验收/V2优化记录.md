# V2优化记录与取舍

## 已落实的调整

| 旧问题 | 调整 | 影响 |
|---|---|---|
| 战役奖励只有横向选择，越玩越强的感觉不足 | 人物与工艺8档，等级相关生命/攻击/技能成长；旧装备补差升级 | 传统和特殊配装都可持续使用 |
| 加零容易改变防御比例或重复乘百分比 | 数值×100同时改减伤常数；百分比读取当前值一次；有完整例算 | 大数值必须参与真实结算 |
| 八关故事过度依赖水务维修 | 扩为32主线、迁徙/粮食/契约/家书/边境居民故事和12支线 | 设施变化对应人物选择与生活后果 |
| 很早就要求谜题理解 | 前3关教学，第4关首次必解，之后逐章增加规则组合 | 初次观察、三级提示、局部复位 |
| 原五族部分身体动作与通用动作重复 | 扩八族并重审动作的独立用途和机会成本 | 无职业门槛，不自动更强 |
| 增加动物容易把每种都变成种族菜单 | 生态与运输动物使用独立对象记录 | 不增加角色职业栏负担 |
| 某些后期谜题完成/复位条件不完整 | 补齐完成谓词、阶段锁定、杆组复位和实际绕行路径 | 标准解可按操作步骤实现 |
| 旧版本奖励/机关记录不能简单改关卡编号 | 旧完成凭证保留历史，V2新关按新账本首通，旧图纸首件不重发 | 防止重复奖励和误跳剧情 |

## 保留的创造空间

套装可2件、3件、5件，也可纯散搭；300个装备ID没有因成长虚增为2400件。职业表面传统，特殊玩法由玩家组合；所有实际触发条件公开，不靠隐瞒数据制造深度。每个人约11项技能配置，主动、被动和自动各自有位置与研习成本。

## 仍需实机决定

8档倍率是首版曲线，地图敌数值和回合压力尚需结合真实战斗调整。32关的文本解法和静态坐标审阅不能证明所有动态局面可恢复。竞技中的两人封路、先手压制及特殊组合采用率必须在原型中观察。发现数值漏洞时修通用规则，避免逐个封杀玩家自创名字。
