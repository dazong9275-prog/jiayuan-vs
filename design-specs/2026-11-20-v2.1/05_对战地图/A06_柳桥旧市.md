# A06 · 柳桥旧市

对战地图规格 v1.0。适用1v1（每人管2棋）与2v2（每人管1棋），双方始终各2棋。引用[统一规则](../00_统一规则_先读.md)；下文补足本图坐标，不另创回合、装备或胜负规则。属于原型设计，未宣称已实机平衡。

## 场地身份与非对称几何

琥汀支流旁的柳桥旧市，关联V2的P13–16湖商转运与P31双河合闸。旧屋墙在西中偏南，摊墙在东南，北侧两处浅水槽错位。

本图的独立玩法是：一块摆桥服务两个位置；开一边会收另一边。主要路线在外沿，桥用于战斗中的跨线协作。

湖畔旧市；西侧屋角、东侧摊墙与一座南偏柳桥，把两条送货路接在不同位置。

西侧C5/D6旧屋角封住直下路线，东侧F5摊墙隔开G5与F6；南沿第7行可做长绕，北线穿E2和G3两个水格。D4栖台临近D5浅沟，桥在D5/E5之间交换。

棋盘9列×7行，A在西、I在东，1在北、7在南；每格建议表现为1.5米。规则一层，地面上台阶/斜坡的美术高度不新增射程优势。列行边界外不可走，不接隐藏通道。四向行走、曼哈顿距离、全图公开，无探索迷雾；装饰远景不参与碰撞。两程不翻转地图，不旋转或镜像内部障碍。

## 两侧任务锚点与复归

开局公开本场采用西侧护送或东侧护送；此地理方向两程固定，第二程只交换两支队伍的实际出生侧与任务角色。例如首程甲从西护送、乙在东拦截，则次程乙从西护送、甲在东拦截；不是把核心起终点同时反转。另一种起始方向作为独立场次配置，双方进入前可见。下表给出两种配置，逐侧测图时都要运行。

| 项目 | 西侧担当护送 | 东侧担当护送 |
|---|---|---|
| 护送前位/后位 | B3 / B5 | H3 / H5 |
| 对方拦截前位/后位 | H3 / H5 | B3 / B5 |
| 可取芯地面 | C2、C6，二选一 | G2、G6，二选一 |
| 远岸检查区 | F、G、H、I列的全部合法可站立格，行1–7 | A、B、C、D列的全部合法可站立格，行1–7 |
| 可交付终点 | I2、I6，任一个完成即进展3 | A2、A6，任一个完成即进展3 |
| 上终点交互格全集 | H2、I1、I3中当时合法空格 | B2、A1、A3中当时合法空格 |
| 下终点交互格全集 | H6、I5、I7中当时合法空格 | B6、A5、A7中当时合法空格 |

每程只存在护送方一枚唯一核心。站在本侧任一有效取芯格，花1AP领取；另一点立即熄灭。本侧另一个点不补芯，敌侧取芯点只作地面。取芯后进展1；持芯在远岸检查区**结束自主激活**记进展2，且至少经历一次对方激活后才允许从终点四邻格花1AP交付。不能同一次激活刚过线便交付，不能被敌方推到检查区就自动过线；巨体/形态规则与锚格判定见统一规则。交接1AP、距离1且接收方同意，每队每轮至多一次。

初始前后位对应行动槽，不按离敌距离自动重排。护送前位→拦截前位→护送后位→拦截后位，每轮相同顺序。4轮共最多16次全局激活；第二程交换任务和实际出生侧，配置锁定，HP/CD/药品/地图/核心完整重置。比较两方各自护送的最高进展，再比较达成该进展的本程全局激活序号。击倒、拉机关、采料均不直接加分。

复归按棋子的实际出生侧查表，优先序为：西前B3→A3→A4→B4，西后B5→A5→A7→B7，东前H3→I3→I4→H4，东后H5→I5→I7→H7。依序跳过不可站立或被占位置；均不可用时，扫描本侧后沿A/B列或H/I列的全部合法格，按「离原出生格曼哈顿距离、行号、列号」升序取首格。仍无可用格则本次计划激活等待，消耗其激活时序并推进CD，下次计划激活再尝试；绝不挤开占用者、删掉机关或把另一方挪走。

复归成功当次只有1AP，限普通移动/架盾，免伤、不能持芯、不能挡路，结束恢复正常占据；若曾移动，结束格仍须合法空置。下一次自身激活才恢复常规2AP。形态次数、药瓶和本程一次性装备不因复归刷新。倒地携芯者把芯掉在锚格；友军同格或四邻格捡回1AP，敌方不能取得、移走或销毁核心，能用站位施压。复归免伤不等于能占敌方已占格。

## 机关、状态与合法操作

A06-M01为C4摆桥手柄。初始「朝东」：E5是桥、D5是浅沟。四邻棋子支付1AP可改为「朝西」：D5是桥、E5是浅沟；再次1AP改回。选择当前状态拒绝。0精力，无冷却。

将收起的桥格有棋子任何占格、掉落核心或临时实体时拒绝整条操作；不能靠翻桥让单位坠落，不能让巨体失去一个支撑格。桥格普通步耗1，浅沟普通不可走；两态均不改变F5/C5实墙。固定镜头显示目标态的桥轮廓，确认后一次性切换逻辑。

所有交互先显示将改变的格与费用，再确认；状态失效时服务器拒绝，确认前不扣费用。机关不能用于推入非法格、夹杀、重复收支生成资源或跳过行动次数。双方均可使用公共机关；每程复位时还原本图初始状态。未写明的「攻击拆墙/烧木成灰/冰冻堵水」均无地图规则，不让视觉效果猜测决定碰撞。

## 不带特殊装备的四激活路线

以下是**无敌人阻挡、普通1×1、MOV3、只步行和任务交互、机关保持初始态**的可执行见证路线，不是最优解或必胜路线。步耗以进入格计，1AP一次步行最多3步耗。未用AP可正常架盾或结束，不结转；路线未依赖攻击清路、交接、种族动作、职业特性或改变形态。示例另一枚友棋不占沿途格。地图必须允许现实对战中的阻拦，静态路线不承诺穿过敌人。

## 对抗设计与停止互等

1v1：南线携芯者可以走第7行，不必争桥。副棋在中路换桥可贴近对方护卫，或隔开两名拦截者。防守者故意站桥能阻止它收起，但本人也要付出未前移的机会成本。

2v2：同伴决定在桥上结束激活前，应知道另一位是否需要转桥；计划箭头显示状态冲突，不替玩家自动让位。拦截双人尽量保持一北一南压力，避免同时追到C5屋角背后后失去对远端目标的覆盖。

4轮截止、两处取芯点和两处交付端使护送方必须建立进展；拦截方按任务合理等待不算违规，双方交换任务后仍需各自完成护送。不得通过地图毒圈、每轮全图扣血或强迫走中心来代替目标压力。两方都藏后沿会使各自护送进展偏低，比较同进展达成时间；本版允许平局，禁止暗中在平局后新增随机先手或突然缩圈。

交付前的等待窗口给拦截者一次明确反应机会，终点不是进入即得分；拦截者可封一个交互格，护送者还有其他邻格或第二终点。必须在真人测试检查「两枚棋稳定封死全部现实送达」而非只看纸面有路。AOE按公开预览命中，瞬发范围与控制仍受全局边界约束；地形不能放大成范围沉默。

## 2×2巨体与静态连通记录

巨化只能选包含原锚格的合法2×2四格；本图没有放宽墙/沟/目标桩占据。锚格不能随意滑到更靠近终点的位置。巨体每次步行的每一个中间四格都须合法，移动减1；交互与过线只看锚格，范围伤害按单位去重。每程一次形态改变，故不存在无限续巨体；形态结束回原锚格，不消灭棋子来强行让路。

原型外部脚本做了如下有限验证：对每个声明机关占格状态，遍历场内所有四格均可站立的2×2足迹，把其中一个足迹视为静止敌方障碍；从本侧任一出生点搜索「可取芯→检查区→任一终点邻格」的四向静态通路。另搜索无该巨体的单携芯者普通4次激活路线，显式包含检查区结束后再延迟交付。浅水2步、每次只有一次步行、每次2AP均参与路线搜索。

| 机关状态 | 合法2×2足迹数 | 造成静态断路数 西/东 | 无巨体4激活路线 西/东 |
|---|---:|---:|---|
| 初始 | 17 | 0 / 0 | 有 / 有 |
| 桥转西 | 17 | 0 / 0 | 有 / 有 |

这份枚举**没有**证明携芯落点被围后的必然回收、两枚敌棋共同封锁、受控后的4轮可达、巨体自身全程可移动、首手公平或双方胜率。两个取芯点在领取后只剩一枚芯，不能用「重新选另一芯」解释残局；残局需要动态对战测试。巨体旁保留普通替代路线的静态要求已经满足，但对局中单位临时占据会改变可走性。任何后续新地物状态都要扩充枚举，不得把这张表挪用为改图后的结果。

## 验收与调参记录

1. 导入时校验9×7格、四出生、四取芯标记、四终点与机关坐标；复制本文两条普通路线逐步回放，核对AP、步耗和全局序号。
2. 两程互换的是队伍任务和实际出生位置，本场护送地理方向及供给/目标坐标固定；镜头可方便玩家旋转，服务器几何与坐标不镜像。
3. 在检查线外被强移进入区、检查区同激活交付、复归激活取芯都必须失败；死亡掉芯、交接确认、断线回连不能重复生成芯。
4. 两种桥态分别验证普通路线；地上核心在E5时朝西失败，先捡起后才可转。巨体覆盖E5但锚格不在E5也不能收桥。剧情的救援潮汐不自动带入本竞技图。
5. 1v1、2v2分别至少做20组配对脚本对局，再做60场双方交换配置的真人/可记录测试；这些数量只用于发现明显问题，不足以断言强度稳定。记录首接触激活、每侧过线率/交付率、最高进展、机关使用次数、不同种族与职业选择率、平局率及倒地后回收率。
6. 同配置交换两侧，若任一侧超过25%的样本在第2轮前失去所有实际推进选择，优先移动掩体/扩大绕路，暂停该图排位；若无互动过线率悬殊，先改路径成本与取芯位置，不靠给一侧加伤害补偿。以更大样本和置信区间再评估胜率偏差。
7. 测试两个近战、两个远程、双防护、无治疗、带一次巨化的配置；特别保留对方连续不前进的反例，验证护送方确实有有风险但可操作的进展选择。

美术可读性：桥转动短而有明确木轴声；柳叶和招牌不遮棋盘。桥格用实心底线，沟格用断线，不能只靠颜色区分。

3D表现先在灰盒中验证格线、遮挡淡化和技能落点。单位平时保持可爱轮廓，演出镜头能短时拉近但不能隐藏敌方下一次行动顺序；跳过演出不改变任何计时或结算。此文件不要求生成模型。

## V2成长隔离

本竞技图所有参赛者固定T1（g=1），生命基线10000、武/术2000、双防2000，伤害P和护盾等已按新量级读取职业及装备卡。服务器从规范T1数据重建配置，不直接采用战役成长后的存档面板。成长、重铸和支线永久旗标不提高本图的AP、射程、药品次数或属性。八种可选种族均纳入同一双向地图验证；本稿尚未宣称新增种族已完成实机公平性测试。
