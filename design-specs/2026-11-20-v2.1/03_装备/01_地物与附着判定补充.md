# 装备引用的地物、附着与动作判定

本表供装备实现与内容审计使用。数值上限服从[统一规则](../00_统一规则_先读.md)。装备效果只能读取地图和技能实际声明的标签；美术名称、颜色、装饰材质不能替代逻辑数据。地图必须明确地物坐标、初始状态、可操作阵营、改变规则和销毁结果。

## 1. 表面与材质

| 标签 | 唯一含义 | 不自动包含 |
|---|---|---|
| 普通地／普通干地 | 可站立，基础进入步耗1；没有浅水或当前湿润表层 | 没有所有障碍、没有独立器械 |
| 土／石／木／铜 | 物件或地面的材质类别，允许多标签，但须数据声明 | 土不一定可挖；铜不一定有电；木不一定可烧毁 |
| 草滩／草丛 | 地图声明可踩的草表面；若声明草遮，才参与视线 | 自动隐身、不可选中、免费回避 |
| 浅水 | 可普通站立的水面；额外步耗须地图声明，未声明时额外0 | 深水游泳、地面电伤 |
| 深水／断口 | 默认不可普通站立，只有明确桥面或能力允许才能通过 | 任何油污、覆霜都不能自行变出承重地面 |
| 碎石／积雪 | 可踩表面；额外步耗读取地图数值 | “穿鞋就一定减步耗”，没有额外步耗时减免无收益 |
| 薄冰表层 | 有底层地面引用的可移除覆盖物 | 永久冰原、冰墙或任意蓝色模型 |
| 冰格 | 地图可能声明滑动方向和时机，未声明则不滑动 | 根据角色朝向临时猜方向 |
| 松土＋可夯实 | 地图允许暂时转为普通土的表面 | 任意泥地、任务承重墙 |
| 草遮／雾遮／霜雾 | 单独的视线标签；根据动作直射/抛射规则判断 | 任意伤害或沉默，也不隐藏已公开目标信息 |
| 高台／坡道 | 地图明确的层高与相邻通行边 | 邻格高度不同就可爬，或3D装饰看起来像坡就可走 |
| 导电地面／铜导边 | 供允许导体交互的招式读取的路径图 | 全地面自动连电、额外命中次数 |

若装备减少一格额外步耗1，算法是 `进入步耗 = max(基础步耗, 原步耗−1)`，不允许变成0。一次移动先对全部路径校验，再提交，不能移动到一半才发现超预算。深水、实墙等不可通行对象不通过减步耗变成可通行。

## 2. 地物与操作权限

| 对象／标签 | 必备字段 | 装备交互边界 |
|---|---|---|
| 矮掩体／矮墙 | 格或边、阻挡方式、是否可毁 | 视线与0.80伤害系数分开处理；只有装备明确同时忽略时两者都变 |
| 实墙／实石墙 | 占格、材质、不可通行、遮线 | 装备没有明说破墙时绝不能穿过 |
| 固定地物 | `movable=false`、所属阵营、材质 | 可以有可拆权限；固定不等于无敌 |
| 可移动地物／轻器械／可搬木箱 | 占格、重量级、允许移动者、目标格规则 | 不能把人物、核心或剧情锁定物件视作普通箱子 |
| 绳锚／挂点 | 坐标、连接边、固定状态、拆除权限 | “保护一次推拉”不免疫拆除或伤害 |
| 可转向旗／悬铃／镜板 | 四向朝向、可操作方、方向对应作用 | 装备只改朝向，不凭空创造攻击或免费再次触发 |
| 压力板 | 连接ID、阈值、读取单位、检查时点 | 重量2不等于两枚棋子、两次得分或两块板同时压住 |
| 阀／重阀 | 状态、交互费用、机关连接、锁定条件 | “重”必须显式标记；不能跳过剧情权限或安全检查 |
| 铜轨＋可断接 | 铜导边ID、轨道通行边、可断状态 | 断电边不自动断轨；本件不得破坏永久任务主线 |
| 可毁木桥 | 耐久、下层地面、毁坏后的安全规则 | 桥上有棋时不令其掉入非法格；护桥不免棋子伤害 |
| 临时桥 | 所有者、到期时点、四格等占位安全检查 | 延寿只到所写时刻；同桥不能被无限续接 |
| 脆墙 | 可毁标记、耐久、销毁后地面 | 普通墙没有脆墙标签则不能仅凭名称打碎 |
| 可拆器械／陷阱 | 所有者、寿命、耐久或拆除费用、已知状态 | 拆己方对象不能满足“拆敌方”收益；对象已消失不能再次结算 |
| 任务物 | 任务ID、是否可受伤、是否可搬、是否可丢下 | PvP核心不可受伤，不能吃护送物护盾，也不算器械 |
| 声音事件门 | 门状态、声音事件ID、对应敌方听觉规则 | 无听觉机制的地图不会因静音产生隐身或信息优势 |
| 照明源 | 覆盖格、持续、开关权限 | 只抵销明确的雾遮；不穿墙、不会自动发现未知区域 |

需要基础拆除、搬运、拾取等操作而地图未声明可操作权限的物件，不能作为合法目标。装备文档明确写1AP的基础操作仍受距离与路径限制。可操作权限不足时整条命令不耗费。

## 3. 人物与格子附着

附着用来源ID和到期事件记录，人物附着与脚下格子表层分开。清除人物油污不会删除地图油迹。任何附着都不会自行造成伤害；伤害必须由明确技能或地物规则产生。

| 附着 | 含义与默认处理 | 不包含 |
|---|---|---|
| 湿润 | 可被明确的水交互读取或清除；持续沿来源卡片 | 固定减伤、定身、自动导电伤害 |
| 油污／油迹 | 前者在人，后者在格；火交互只按施术卡片执行 | 每轮自动燃烧，未写明则不产生附加伤害 |
| 覆霜 | 可清除的非控制表层；不等于沉默或冻结 | 禁止激活、免费滑行 |
| 充电 | 人物或物件的非伤害输入标记；可满足显式电机关条件 | 增加术力、下一击自动附伤 |
| 燃烧标记 | 物件状态标签，具体伤害和持续由来源定义 | 木、铜材质自动相互转换 |
| 固定标记 | 暂停该物件的可移动权限 | 禁止其拆除、伤害、开关或销毁 |
| 稳地 | 抑制该格明确的一项额外步耗，持续按来源 | 清除水材质或增加基础移动 |
| 系绳 | 该来源对强移距离的限制；离锚/拆锚按卡片解除 | 第二次受强移资格或额外反应 |
| 泊点／咏唱印 | 明确一格与来源ID，按卡片检查 | 额外进展分或自动瞬移 |

重复同类附着没有隐含叠层；如技能声明层数，才按该技能层数操作。“清除一层”对无层级普通附着等于移除该附着，不清控制保护期、任务标记或冷却。

## 4. 动作、事件与伤害取值

- **武器主动**包括主手普攻和招牌动作；卡片进一步要求“单格近战、读取武力”时，两条件都必须成立。
- **咏唱、武技、器械**是发动类型；**物理、法术**是伤害通道；**武力、术力**是取值字段，三者独立。S151只换本次目标防值，S152只换本次取值，均不复制第二次伤害。
- **直射、抛射**须技能字段明确。改变观察格不改变施术者锚格，射程仍按原锚格；忽略一段雾不等于忽略墙。
- **即时与延时**读取技能结算时点。S194不可改变延时技、范围技或单格沉默。S166取消延时技后仍保留统一规则规定的该激活伤害动作占用。
- **主动伤害事件**只指角色提交的主动作伤害。装备次级伤害、付盾代价、自付生命等不得满足“被敌方主动命中”的物品触发条件。
- 护盾低于代价、精力不足、目标消失、形态/持芯不允许、当轮已用次数或反应已用时，预览明确失败原因；不先付款再悄悄跳过条件。
- 无AP费用的可选物件触发跟随所属主命令提交；不是另一次激活或无限反应窗口。敌方事件引起的可选防护统一占本轮一次反应，卡片有说明的被动计数除外。

## 5. 内容覆盖审计

每个依赖地物的装备需至少满足一条：现有地图存在有坐标的合法对象；技能可合法部署该对象；训练场有明确可生成的对象样例。不得用“将来地图会有”冒充已可玩的完整价值。

训练场必须提供下列固定夹具：可开启的压力板与双阀、两类铜桩与断接铜轨、湿地与薄冰底层、可转镜板、草遮与霜雾、损伤木桥与安全底层、可拆敌械与友械、固定/活动绳锚、明示已知陷阱和声音门。夹具面板只演示单件行为，不显示跨装备成套解法。

发版检查必须给每条依赖记录实际地图/技能/夹具ID。夹具证明单件能执行，不证明竞技价值；仅在夹具可用而当前地图无用的物件应标记适用范围，不混入新手传统配装建议。当前文件是逻辑判定规格，不宣称引擎夹具已实现或全地图覆盖已经通过实机测试。
