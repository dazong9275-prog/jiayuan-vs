# S048　旧栈照纹镜

| 字段 | 规格 |
|---|---|
| 装备ID | `S048` |
| 种类 | 特性装备 |
| 槽位 | `OH` |
| 器具类型 | 镜 |
| 固定基础属性 | 武力+100、护甲+400、法抗+600；其余属性+0 |
| 正向预算 | 武力100÷100 + 护甲400÷200 + 法抗600÷200 = 6（T1归一预算；高档先除工艺倍率） |
| 角色限制 | 八族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 持用

单手副手，须主手为空或单手器具。未写明的架盾、基础机关交互仍采用统一规则，外形不自动赋予额外防御或导电能力。

## 特性

花1 AP、1精力照向距2可见的可读刻纹物件，揭示其已经定义的开关状态至本轮末，CD1；不显示敌人隐私配置或地图外区域。

## 用途与应对

帮助远读机关，近身交互能做同样事。

## 结算约束

本节数值上限按T1显示，战役上限按受益/受击者成长档换算；动作次数不变。

本件只能改变上述明确操作。普通护盾取较高且总上限1600；治疗每目标每轮2400；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计800。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

无刻纹标签的物件不会收到额外状态信息。

## 获得与工坊

完成 `P32` 归湾长夜后，共建工坊的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「定握距、固定外框并检查接点→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

## 联动边界

玩家界面显示本件自身说明、有效目标、实际费用和预览结果。开发检查同一机制对八族及各职业一致生效；任何跨职收益都需通过该角色当前属性、已选技能和本件实际操作形成，不按搭配名字触发。

## 战役工艺档与竞技

上述人物生命、攻防、威力、治疗和盾以T1显示。T1–T8工艺倍率依次为1/1.25/1.50/1.75/2/2.25/2.50/2.75；固定属性乘本件工艺倍率，明示人物伤害/盾/治疗的定值随装备档成长并受目标档上限约束。HP百分比、机关结构耐久刻度、AP、精力、格数、CD、次数与预算不放大。器械若有战斗HP须用战斗HP字段，不能把结构耐久当人物生命。武器招牌P按人物成长档计算，不再乘第二次装备档。系列额外属性按成员最低工艺档计算。竞技强制T1，特性条件不因成长扩大。详见[数值成长](../../08_成长与构筑/04_战役成长与大数值.md)。
