# BI04 · 湖泊群岛建模语言与制作指导

适用范围：WR04；P13–16、A03/A06水岸参考。本文件是未来资产制作工作单，不表示模型已生成。先遵守[统一制作约定](../制作约定.md)，再读对应地图的逐图工作单；生态描述不能覆盖地图的真实通行与机关状态。

## 1. 第一眼要认出的特色

琥汀是相连湖盆、浅沙脊和可拆高脚木路。水色由深浅与底质形成层次，岛形偏斜，不用圆岛配环形码头。

大形是两片错位浅滩和一条偏侧的深水带。中形是低矮湖石、桩桥、浮标列与船屋。小形是水线、纤维绳、桨磨痕和细波，避免每平方米都塞贝壳。

## 2. 地面、边界和实体构造

浅水/深水逻辑边界先按玩法图锁定，水面几何可以连续但底色、边缘泡沫和UI须能区分。浅水不是自动可涉，深水也不因贴图透明而可走。桥的顶面整格对齐，桩和浮筒作为支撑视觉；可动桥面与底座独立。

比例固定为1格1.5m，普通可走顶面Y=0。地面模块厚0.20m向下，辅助拼接步长0.25m。场景外壳可以有明显体积，但不能让可走面看起来出现未声明台阶。原图不占格的机关优先采用地边本体与0.04m以内嵌入标识；大型机壳放外圈并以管线/绳索连接到原交互格。

## 4. 配色与材质起点

| 表面 | 基色参考HEX | 粗糙度 | 金属度 |
|---|---|---|---|
| 浅底沙 | #C8BA86 | 0.85–0.95 | 0 |
| 浅湖 | #65A59A | 0.12–0.28 | 0 |
| 深湖 | #355D6D | 0.10–0.25 | 0 |
| 潮木 | #74634D | 0.45–0.70 | 0 |
| 帆布 | #D7C89D | 0.75–0.90 | 0 |

HEX是sRGB配色方向，实际着色器会转换到线性空间，不能把这些数值直接当灯光强度。粗糙度与Unity Smoothness相反：需要Smoothness时使用1−roughness。金属度只对裸露金属设1，灰尘、锈层、木石水雪设0；不要把所有旧金属简单设0.5。清洁与湿润通过分层遮罩表达，不凭“越亮越精致”。

生态共享贴图起点2048²，机关1024²，小装饰512²；非重复地面优先共享平铺材质加低频色斑，禁止为每格生成独立4K。PC基准纹素密度：近景机关512px/m，普通地面256px/m，远景128px/m；移动档可分别减半至256/128/64px/m，最终按默认镜头可见像素和预算调整。UV0接缝放背面/低可见面；UV1用于烘焙时须不重叠并留边。

## 5. 灯光、镜头与层次

主光偏东南，起点6000K，水面反射只保留柔和宽亮带。将高光压到不会淹没危险格线的程度；可先用不透明浅水材质通过读图，再逐步启用深度颜色和少量透明。远水反射细节少于近岸。

默认斜俯视相对水平55度、南侧方位偏25度、正交构图。首先用无贴图灰模从四个90度方向检查轮廓和交互点，再上材质。前景遮挡物必须有独立视觉壳淡化方案，视觉消隐不改变逻辑遮挡或碰撞。1920×1080通过后以1280×720复验，不能只用近距离截图判断精细度。

## 6. 植被、动物与生活痕迹

水草贴底，不铺满水面；芦苇集中在一侧入湖口，石岸以低苔为主。鱼群为低频远景，不追着玩家指针游动。漂叶和波纹不能模仿可选目标边框。

湖岸不同年份刻度说明水位波动，重绑绳结说明共享码头，船屋折叠板说明迁居方式。机关镜面与普通船窗用明显形状区分。

三层环境叙事按距离分配：远处读地理与主要建筑，中距离读居民如何使用空间，近处才读补丁/记录/个人物件。可选故事物不发与主目标同样亮度的光；没有逻辑ID的动物只做低频环境行为，不占格、不触发战斗、不挡射线。

## 7. 可直接交给建模AI的分段任务

一次只提交一个阶段和一个资产ID，并附批准的尺寸、俯视草图、正侧背示意及所需状态。没有参考图时先要求AI提交文字尺寸表和结构分解，不直接生成整张“漂亮地图”后再猜碰撞。

### 第一步：单件结构样板

```text
项目：家园；生态：BI04 湖泊群岛。只制作本次指定模块，不建立整张关卡。
制作1.5m桩桥单元，顶板按格边对齐，底部两条纵梁与支点完整。提供直段、岸接段和独立旋转桥面；桥面运动枢轴在逻辑铰点，不在几何中心。禁止自动加栏杆堵掉玩家移动边。
统一单位米，保留中心/底部约定枢轴，应用缩放但不重复做坐标轴转换。提交正、后、左、右、俯视与线框检查视图；不以正面截图替代完整网格。
```

### 第二步：材质样板与模块变体

```text
沿用已批准BI04样板结构和比例。按本文件色板做基础PBR材质，先提供中性灯光下的基色、粗糙度、金属度、法线分离预览。
制作A/B/C三种轮廓或磨损变体，接口和枢轴保持一致。改变轮廓大形优先于增加微小裂纹；真实厚度、侧背面与接触支撑不可省略。
只对确实适合的叶片/布片使用薄面；承重墙、桥、屋壳、岩体必须有完整体积。
```

### 第三步：在批准棋盘上排布

```text
读取本关原始逻辑格图、对象表及BI04逐图工作单。先锁定可走格、出生、交互、核心/出口和所有机关状态。
使用批准模块搭地表和外圈壳，再放一个主要地标；原图未定义的装饰一律不得产生碰撞、遮线、导航边或高度变化。
每完成一层提交同一固定相机视图；没有通过灰模读图前，不继续叠装饰。机关外观只响应既有状态，不用动画碰撞控制逻辑。
```

### 第四步：交付与返工

```text
提交源文件、交换网格、共享贴图、LOD与独立碰撞代理命名表、状态部件清单和导入说明。当前任务要求的是未来资产清单，不得声称已通过实际引擎帧率测试。
发现问题只修指定资产和原因，并提交同机位前后对照；不得借优化重新改关卡布局。
```

## 8. 粗糙结果的具体修法

若湖水像透明塑料，去掉过强折射和高频法线，改用深浅底色；若桥像悬浮地板，补桩梁与湿线；若浅深边界看不懂，增加底色和岸缘轮廓，而不依赖纯色提示。

| 看到的问题 | 先检查 | 具体返工动作 |
|---|---|---|
| 地面是巨大平板，只有贴图变化 | 是否只有一张面、外圈没有层次 | 保留逻辑顶面，补独立边坡/岸层/岩壳和接触阴影；大高差放边界 |
| 墙和石头像没有重量的积木 | 受力接触、比例、统一倒角 | 补基座/承托，统一可见倒角尺度，减少随机旋转 |
| 正面好看但侧背空洞 | 法线、非流形边、薄面滥用 | 闭合实际体积，修法线；不是开双面材质 |
| 微细节很多但缩远糊成一片 | 纹素密度、法线频率、镜头大小 | 合并低频色块，削减微裂纹和高反差边线，保留主轮廓 |
| 地标挡住角色和机关 | 四向视图、冠幅、前景层 | 外移大体量，拆视觉壳淡化，保持逻辑代理不变 |

## 9. 验收门槛

1. 用1.1m角色参照和3×3m巨体足迹检查可走格；不能出现视觉上可站但逻辑禁止、或视觉堵死却实际可走的误导。
2. 同一模块看正侧背和底部，检查闭合体积、枢轴、接口缝、法线和未应用负缩放；薄面例外必须列理由。
3. 从四个相机方向识别主要地标、可走范围、机关输入和完成状态，必要数字不依赖贴图文字清晰度，采用UI/独立符号覆盖。
4. 草/雪/水等环境效果关闭后仍能理解地形，粒子不能成为读取状态的唯一方式。
5. 按每图工作单测初态、成功、错误、复位外观；视觉不得自发改变通行或奖励。
6. 统计LOD三角、材质槽、贴图实际驻留和透明层；本文预算是制作目标，帧率必须在目标设备Profiler验证。
