# 网格、UV、材质与灯光制作标准

本文件给执行建模的AI和美术使用。参数是首轮制作起点，最终以玩法相机、引擎材质和目标设备审查决定；不能只根据离线渲染截图宣布合格。

## 1. 网格要有体积和结构

地面、墙体、岩石、木梁、箱体、桥板等实体必须有完整合理的侧背和底面。桥面厚0.12–0.25m，木梁按跨度做0.10–0.25m截面，金属外壳薄壁可0.01–0.03m，壳口必须收边；不得用单面贴图替代桥底和墙背。远景完全不可见面可经剔除审批优化，先制作完整母件，再注明被删面的相机约束。

草叶、薄纸、旗布可按设计使用薄面，必须单独列入薄面白名单。双面材质是薄面表现方式，不是补失踪背面的修复。需要厚度或侧面轮廓时使用薄体网格。所有法线一致朝向，镜像生成的物件应用变换后重检切线和绕序。

结构上应能解释重量：大石基底贴地，粮仓梁落在柱头，缆绳确实接到锚，阀柄连轴而非浮在管上。斜梁可以只在不可走墙块/外延中出现；可走地面不加绊脚横梁。木板之间允许细缝，但不能透视到无建模的空世界。

## 2. 拓扑与细节层级

轮廓决定几何密度。大岩块用数个明确面向和主要裂缝，木构优先倒角、端面和接头，金属优先外轮廓、轴承、圆口。小划痕、木纹毛刺、细颗粒放到法线/粗糙图。不要把同等密度的噪声平均撒满所有表面。

| 资产 | LOD0目标三角数 | 主要几何用途 | 可烘焙细节 |
|---|---:|---|---|
| 地面1格 | 300–800 | 收边、主起伏、地层侧面 | 砂砾、细裂、泥印 |
| 岩块 | 600–1800 | 断面轮廓、底座、主要凹口 | 微裂和矿纹 |
| 建筑壳/洞壁组 | 3000–9000 | 梁柱、门口、屋檐、洞口边 | 凿痕、木纹 |
| 核心机关 | 2000–6000 | 可动件、轴承、手柄和刻度轮廓 | 螺丝浅槽与细刮痕 |
| 焦点地标 | 8000–16000 | 能在整图相机看到的剪影 | 背侧细雕 |
| 小道具/植物簇 | 150–700 | 外形与关键辨识部位 | 小标签、叶脉 |

这些是资产类别起点，不能把每个模块都用到上限再声称整图达标。大块墙体的近景投影比小地标大时可重新分配预算。保留非破坏性的高模工作源，低模先定硬边与UV缝，再烘焙切线法线。最终三角化副本用于导出，避免DCC和引擎三角化不同造成法线接缝。

## 3. UV和纹理分配

普通可见场景表面起始texel density为256px/m，焦点机关近景可512px/m，远景128px/m。共享2048贴图在256px/m下约覆盖8m×8m的等密度正面面积；复杂曲面/UV空隙会降低利用率，不能直接按地图面积一张铺满。先统一密度，再决定图集组合。

UV0供颜色、法线与通道图。重复木梁/石条可共用平铺或trim sheet；独特任务标记不能镜像成倒字。UV1备用给光照烘焙，必须无重叠并保持有效边距。1024图上相邻岛边距起点8px，2048为16px，检查低mip是否串色；烘焙输出做padding扩边。

BaseColor不烘焙方向光、强AO、白色镜面高光或固定任务数字。AO作为独立通道或弱乘层，凹槽不可压成纯黑。Normal使用切线空间并按工具约定导入；OpenGL/DirectX绿色通道差异通过一个标准凹凸样板检查，不对全库盲目翻转。

建议导出中性标准贴图：BaseColor、Normal、Roughness、Metallic、AO、可选Emission/Opacity。Unity URP需要的Smoothness=1−Roughness；是否写入Metallic alpha等通道取决于所用shader，按导入清单转换，保留原始各通道图，不让多个软件各反转一次。

## 4. 材质起始范围

| 材质 | Metallic | Roughness | 制作重点 |
|---|---:|---:|---|
| 干土/砂岩 | 0 | 0.70–0.95 | 细颗粒只影响法线/粗糙，主色块保持清楚 |
| 湿泥/湿石 | 0 | 0.25–0.55 | 湿润按水位/积水洼分布，不全表面涂亮 |
| 木材 | 0 | 0.55–0.80 | 纵纹与端纹分开，梁受力方向清楚 |
| 油漆/布料 | 0 | 0.65–0.90 | 干净可读色块，边缘磨损少量集中 |
| 裸铜/铁 | 1 | 0.25–0.55 | 基色和反射依金属工作流，不能靠黄色塑料冒充铜 |
| 锈蚀/氧化层 | 0 | 0.70–0.95 | 与裸金属遮罩分开，不能整面Metallic=1的锈 |
| 新雪 | 0 | 0.75–0.95 | 冷暖阴影与压痕分层，不纯白剪裁 |
| 压实雪/粗冰 | 0 | 0.35–0.65 | 保留路面可读性，减少高频闪光 |
| 清冰/水面 | 0 | 0.08–0.25 | 反射受限；清水IOR如受支持用1.333 |

不得把“粗糙度低”当作质量高。雪、木、泥具有不同反光范围和细节尺度，远距离也应分辨。透明对象越多越容易降低可读性，水面优先不透明着色加岸边深浅渐变；真正需要透明时，记录最大叠层、深度写入与投影行为。地格描边和任务标记不得被水面覆盖。

## 5. 颜色组织

每生态准备背景主色、地面主色、建筑主色、环境点缀和机关强调五类。机关强调色必须加独立形状/刻度，不与敌方危险预告同形同色。黑白缩略图中单位与地面、目标牌与背景仍要分开，避免靠饱和色堆叠区分。

不要用纯白雪#FFFFFF铺满，也不要用纯黑洞壁#000000代替深度。保留灰阶余量让技能光、霜雾和护盾能显示。草原为宽阔水平形体，雪区为风积层和裸露岩线，洞区为承重拱与切口，湖区为侵蚀岸线和水位痕；形体先于色板。

## 6. 灯光先服务读图

先在中性检查场使用一盏主光、环境填光、固定曝光观察材质。批准后再设置剧情气氛。URP普通方向光强度起点1.0–1.5、环境填光按相对亮度0.25–0.50试调；使用物理lux单位的管线应另设曝光基准，不直接照搬上述无单位数值。

太阳方向与地图地貌和天气一致，阴影尽量斜向穿过空白背景而非覆盖关键机关。限定实时投影灯数量，装饰灯主要用Emission和烘焙/探针表达。洞穴使用入口主光和暖灯的局部层次，后壁有弱填光；夜间归湾用窗灯/堤灯形成路线，但所有可走格仍有基础照度。

自动曝光在战斗中建议固定或限制变化速度，不能技能爆闪后让整盘突然变黑。雾应退到棋盘外围/远景，近棋盘只用不会遮掉格边的薄层。雪粒、尘、火花不承载必要线索；关闭特效后仍能解谜。

## 7. 视觉复核的固定顺序

1. 中灰无材质看轮廓、厚度和支撑。
2. 单色无灯影看分区和任务标记。
3. 中性光看粗糙、金属和法线。
4. 关卡气氛光看可读性。
5. 四向相机、720p、低特效看机关与角色脚点。
6. 动态门桥/天气状态切换看接缝、穿插和错误高光。

如果前一步不合格，不用下一步掩盖。比如岩石轮廓差就返回网格，法线阴影错误就查切线和UV，棋盘太乱就先减装饰数量，不先把镜头抬高到看不清角色。
