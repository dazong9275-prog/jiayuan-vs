# B004　霜林弯刀

| 字段 | 规格 |
|---|---|
| 装备ID | `B004` |
| 种类 | 普通基础装备 |
| 槽位 | `MH` |
| 器具类型 | 刀 |
| 固定基础属性 | 术力+4、法抗+4；其余属性+0 |
| 正向预算 | 术力4÷1 + 法抗4÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 武器操作

- 单手，占主手；可以搭配一件合法副手。
- 普攻取值为武力→护甲，P12，1 AP、0精力，距离1，四向相邻敌人一名。使用后占本次主动伤害动作。
- 招牌「回斩」为1 AP、1精力、CD1。指定一个相邻敌人，P14，单格系数1.00，结算后可免费改面向一次，仍占本次伤害动作。 基础读取武力→护甲，发动标签为武技。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 基础用途

本件只提供表内固定属性，主手另提供该类型的普攻与招牌动作。 玩家用它比较同槽装备的生命、输出和防御取舍。它作为工坊展示和战斗教学的稳定参照，属性没有随机词条、强化等级和同名套装奖励。

## 最小验收

在所有装备槽清空的训练角色上只装本件，逐项面板变化应精确等于属性表；卸下后回到原面板。不得额外改变移动、AP、精力上限或行动顺序。

## 获得与工坊

完成 `P08` 归湾长夜后，共建工坊的同级研究列表永久开放本件。首次试制免费领取，可直接领取供训练与换装。 工序按「制柄、固定工作端并校直→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。
