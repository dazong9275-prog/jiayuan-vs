# B022　砺风皮盾

| 字段 | 规格 |
|---|---|
| 装备ID | `B022` |
| 种类 | 普通基础装备 |
| 槽位 | `OH` |
| 器具类型 | 盾 |
| 固定基础属性 | 生命+4、术力+2、护甲+4、法抗+2；其余属性+0 |
| 正向预算 | 生命4÷4 + 术力2÷1 + 护甲4÷2 + 法抗2÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 持用

单手副手，须主手为空或单手器具。未写明的架盾、基础机关交互仍采用统一规则，外形不自动赋予额外防御或导电能力。

## 基础用途

本件只提供表内固定属性，角色通用动作不因本件改变。 玩家用它比较同槽装备的生命、输出和防御取舍。它作为工坊展示和战斗教学的稳定参照，属性没有随机词条、强化等级和同名套装奖励。

## 最小验收

在所有装备槽清空的训练角色上只装本件，逐项面板变化应精确等于属性表；卸下后回到原面板。不得额外改变移动、AP、精力上限或行动顺序。

## 获得与工坊

完成 `P02` 砺风牧道后，游牧锻台的同级研究列表永久开放本件。首次试制免费领取，可直接领取供训练与换装。 工序按「定握距、固定外框并检查接点→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

## 联动边界

玩家界面显示本件自身说明、有效目标、实际费用和预览结果。开发检查同一机制对五族及各职业一致生效；任何跨职收益都需通过该角色当前属性、已选技能和本件实际操作形成，不按搭配名字触发。
