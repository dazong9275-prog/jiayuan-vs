# B041　芦湾取样瓶

| 字段 | 规格 |
|---|---|
| 装备ID | `B041` |
| 种类 | 普通基础装备 |
| 槽位 | `TL` |
| 器具类型 | 基础工具 |
| 固定基础属性 | 武力+4、护甲+2、法抗+2；其余属性+0 |
| 正向预算 | 武力4÷1 + 护甲2÷2 + 法抗2÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 携带

本件固定占一个对应装备槽。物件名称中的材料只用于外观说明，战场交互以本件明确的效果及目标标签为准。

## 基础用途

本件只提供表内固定属性，角色通用动作不因本件改变。 玩家用它比较同槽装备的生命、输出和防御取舍。它作为工坊展示和战斗教学的稳定参照，属性没有随机词条、强化等级和同名套装奖励。

## 最小验收

在所有装备槽清空的训练角色上只装本件，逐项面板变化应精确等于属性表；卸下后回到原面板。不得额外改变移动、AP、精力上限或行动顺序。

## 获得与工坊

完成 `P05` 霜冠旧栈后，雪线工棚的同级研究列表永久开放本件。首次试制免费领取，可直接领取供训练与换装。 工序按「整理内格、固定提带并核对用途标记→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

## 联动边界

玩家界面显示本件自身说明、有效目标、实际费用和预览结果。开发检查同一机制对五族及各职业一致生效；任何跨职收益都需通过该角色当前属性、已选技能和本件实际操作形成，不按搭配名字触发。
