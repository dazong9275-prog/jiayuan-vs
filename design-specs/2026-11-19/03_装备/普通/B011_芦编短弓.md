# B011　芦编短弓

| 字段 | 规格 |
|---|---|
| 装备ID | `B011` |
| 种类 | 普通基础装备 |
| 槽位 | `MH` |
| 器具类型 | 弓 |
| 固定基础属性 | 生命+4、武力+1、术力+3、法抗+2；其余属性+0 |
| 正向预算 | 生命4÷4 + 武力1÷1 + 术力3÷1 + 法抗2÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 武器操作

- 双手，占主手和副手；副手必须空。
- 普攻取值为武力→护甲，P12，1 AP、0精力，距离2–4的一名可见敌人，直射，受矮掩体修正。使用后占本次主动伤害动作。
- 招牌「穿弦」为1 AP、2精力、CD1。选择同一行列距离2–4的首名可见敌人及其后一格，P12、直线系数0.75；实墙阻断，友军不受伤。 基础读取武力→护甲，发动标签为武技。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 基础用途

本件只提供表内固定属性，主手另提供该类型的普攻与招牌动作。 玩家用它比较同槽装备的生命、输出和防御取舍。它作为工坊展示和战斗教学的稳定参照，属性没有随机词条、强化等级和同名套装奖励。

## 最小验收

在所有装备槽清空的训练角色上只装本件，逐项面板变化应精确等于属性表；卸下后回到原面板。双手器具须使副手无法装入。

## 获得与工坊

完成 `P07` 双河争闸后，合流测绘台的同级研究列表永久开放本件。首次试制免费领取，可直接领取供训练与换装。 工序按「制柄、固定工作端并校直→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。
