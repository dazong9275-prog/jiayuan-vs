# S069　湖镜观测·霜冠覆雪毡

| 字段 | 规格 |
|---|---|
| 装备ID | `S069` |
| 种类 | 特性装备 |
| 槽位 | `TL` |
| 器具类型 | 工事 |
| 固定基础属性 | 武力+1、术力+1、护甲+6；其余属性+0 |
| 正向预算 | 武力1÷1 + 术力1÷1 + 护甲6÷2 = 5；另按系列满足件数计套装奖励 |

## 携带

本件固定占一个对应装备槽。物件名称中的材料只用于外观说明，战场交互以本件明确的效果及目标标签为准。

## 特性

每关/程一次，1 AP、0精力铺到距1普通地面，覆盖该格已有的单次寒风地面伤害，直到下一轮末；不消除敌方霜技能伤害。

## 用途与应对

可保护狭路格，对方也能走。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

一格毡多名角色经过只屏蔽一次环境触发后消耗。

## 获得与工坊

完成 `P05` 霜冠旧栈后，雪线工棚的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「整理内格、固定提带并核对用途标记→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

## 联动边界

玩家界面显示本件自身说明、有效目标、实际费用和预览结果。开发检查同一机制对五族及各职业一致生效；任何跨职收益都需通过该角色当前属性、已选技能和本件实际操作形成，不按搭配名字触发。

## 系列与自由搭配

本件属于 **F07 湖镜观测**，单独穿戴时保留全部上述基础属性和单件效果。不同ID计件，重复实例不重复计件，双手武器仅计一件。

- 装备本系列3件时，额外术力+2、法抗+2（此档新增3预算）。

各档累计；不足件数立即失去对应奖励。成员：S029, S103, S069。主手工具绑定，不能同时自由携带另一种强工具。套装不自动改职业、取值、技能槽或形态次数。详见[系列与套装规则](../01_系列与套装规则.md)。
