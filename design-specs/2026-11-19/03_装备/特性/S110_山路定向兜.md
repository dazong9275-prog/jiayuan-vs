# S110　山路定向兜

| 字段 | 规格 |
|---|---|
| 装备ID | `S110` |
| 种类 | 特性装备 |
| 槽位 | `HD` |
| 固定基础属性 | 武力+1、术力+2、法抗+6；其余属性+0 |
| 正向预算 | 武力1÷1 + 术力2÷1 + 法抗6÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |
| 切换时机 | 营地与竞技备战；进入关卡或一场两程对局后锁定 |

## 单件规则

长枪沿未移动过的方向出手后，可以调整朝向。

## 发动与结算

- **时机与费用：**自身武技主动结算后且本激活未步行，付1精力。
- **结果：**立即将自身面向改为所选四向之一，并获得4点护盾。
- **次数与边界：**不改变攻击区域或补击；护盾至自身下次激活开始，每轮一次。

## 用途与反制

从另一侧准备打击，或用强移破坏站位。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

先刺东再转北，东边目标只受原来一次伤害，转向没有新命中。

## 获得与锻造

完成 `P07` 双河争闸后，共闸检修棚的同级研究池开放本件固定图纸。首次登记图纸后免费试制首件；研究池逐项选择，不随机抽取。领取以账号与装备ID幂等登记，重复确认只返回已有制作记录，不能出售重复生成的物件换材料。后续制作与重铸遵循成长文档的统一经济规则。本件来源是关卡完成后的工坊研究池，不声称关卡地面上存在一个未标坐标的宝箱。竞技同版本借用库提供同规格。
