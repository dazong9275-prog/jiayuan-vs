# S199　逆潮木哨

| 字段 | 规格 |
|---|---|
| 装备ID | `S199` |
| 种类 | 特性装备 |
| 槽位 | `AC` |
| 固定基础属性 | 生命+4、护甲+10；其余属性+0 |
| 正向预算 | 生命4÷4 + 护甲10÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |
| 切换时机 | 营地与竞技备战；进入关卡或一场两程对局后锁定 |

## 单件规则

核心刚被交出时，可以给下一段路留下一个可见记号。

## 发动与结算

- **时机与费用：**本队本轮合法交接核心成功，且自己为交出者，额外付1精力。
- **结果：**选择距2一个可见普通地格为泊点；本轮接收者在该格结束自主激活时获得8盾至其下一次激活开始。
- **次数与边界：**每程一次；只能一个泊点，不加移动、进展、交接次数；若未到则到轮末消失。

## 用途与反制

占住泊点、改变攻击路线或逼持芯者绕行。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

泊点在检查线前不会自动记过线，抵达只加盾；倒地掉芯不算交接。

## 获得与锻造

完成 `P04` 琥汀断堤后，湖堤工房的同级研究池开放本件固定图纸。首次登记图纸后免费试制首件；研究池逐项选择，不随机抽取。领取以账号与装备ID幂等登记，重复确认只返回已有制作记录，不能出售重复生成的物件换材料。后续制作与重铸遵循成长文档的统一经济规则。本件来源是关卡完成后的工坊研究池，不声称关卡地面上存在一个未标坐标的宝箱。竞技同版本借用库提供同规格。
