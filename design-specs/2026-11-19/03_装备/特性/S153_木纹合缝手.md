# S153　断堤联作·木纹合缝手

| 字段 | 规格 |
|---|---|
| 装备ID | `S153` |
| 种类 | 特性装备 |
| 槽位 | `HN` |
| 固定基础属性 | 生命+4、术力+2、法抗+4；其余属性+0 |
| 正向预算 | 生命4÷4 + 术力2÷1 + 法抗4÷2 = 5；另按系列满足件数计套装奖励 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |
| 切换时机 | 营地与竞技备战；进入关卡或一场两程对局后锁定 |

## 单件规则

把自己的护带拆给已经受损的构件。

## 发动与结算

- **时机与费用：**自身激活有至少8普通盾，付1AP移除8盾，选距1己方可修木构件。
- **结果：**构件恢复6耐久，不超过原最大耐久。
- **次数与边界：**每轮一次；不是角色治疗，不修任务核心、倒地角色或已毁物件；次级修复不触发器械技能。

## 用途与反制

攻击失盾的修补者，或一次击毁构件。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

构件剩2/8耐久修至8，自己16盾变8；自己只有7盾拒绝整条命令。

## 获得与锻造

完成 `P02` 砺风牧道后，牧道皮作的同级研究池开放本件固定图纸。首次登记图纸后免费试制首件；研究池逐项选择，不随机抽取。领取以账号与装备ID幂等登记，重复确认只返回已有制作记录，不能出售重复生成的物件换材料。后续制作与重铸遵循成长文档的统一经济规则。本件来源是关卡完成后的工坊研究池，不声称关卡地面上存在一个未标坐标的宝箱。竞技同版本借用库提供同规格。

## 独立使用与组合

单件规则在散搭时完整生效。若被套装目录列入某同名系列，套装属性按独立套装规则和总预算结算，不改变本件条件、不增加第二个职业身份。未列入系列的物件没有隐含套装奖励。玩家端准确显示本件属性与发动规则，不自动公布跨装备构筑配方。

## 系列与自由搭配

本件属于 **F12 断堤联作**，单独穿戴时保留全部上述基础属性和单件效果。不同ID计件，重复实例不重复计件，双手武器仅计一件。

- 装备本系列2件时，额外生命+4、护甲+2（此档新增2预算）。
- 装备本系列5件时，额外武力+1、护甲+2、法抗+2（此档新增3预算）。

各档累计；不足件数立即失去对应奖励。成员：S057, S107, S153, S178, S077。五件包含副手与工具，脱离可交互地形后可能不如散件。套装不自动改职业、取值、技能槽或形态次数。详见[系列与套装规则](../01_系列与套装规则.md)。
