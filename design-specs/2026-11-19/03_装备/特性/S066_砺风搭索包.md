# S066　砺风搭索包

| 字段 | 规格 |
|---|---|
| 装备ID | `S066` |
| 种类 | 特性装备 |
| 槽位 | `TL` |
| 器具类型 | 工事 |
| 固定基础属性 | 护甲+6、法抗+6；其余属性+0 |
| 正向预算 | 护甲6÷2 + 法抗6÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 携带

本件固定占一个对应装备槽。物件名称中的材料只用于外观说明，战场交互以本件明确的效果及目标标签为准。

## 特性

每关/程一次，1 AP、2精力在相邻带锚单格浅沟搭索，双方可通过至下一轮末，有人时等离开再消失。携核心者不能走索。

## 用途与应对

额外通路同时服务双方，锚缺失时无用途。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

桥上有人时到期不删除脚下合法地面。

## 获得与工坊

完成 `P02` 砺风牧道后，游牧锻台的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「整理内格、固定提带并核对用途标记→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

## 联动边界

玩家界面显示本件自身说明、有效目标、实际费用和预览结果。开发检查同一机制对五族及各职业一致生效；任何跨职收益都需通过该角色当前属性、已选技能和本件实际操作形成，不按搭配名字触发。
