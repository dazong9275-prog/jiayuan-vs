# S164　灰绳卸扣

| 字段 | 规格 |
|---|---|
| 装备ID | `S164` |
| 种类 | 特性装备 |
| 槽位 | `HN` |
| 固定基础属性 | 术力+2、护甲+6、法抗+2；其余属性+0 |
| 正向预算 | 术力2÷1 + 护甲6÷2 + 法抗2÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |
| 切换时机 | 营地与竞技备战；进入关卡或一场两程对局后锁定 |

## 单件规则

受拉扯时，可主动解开身边可拆绳子的最后一道扣。

## 发动与结算

- **时机与费用：**敌方宣告对自己强移，在反应窗口消耗反应机会、1精力，选距1可拆绳锚。
- **结果：**拆除该绳锚，然后按原攻击结算；若拆除会使桥上任何人非法站位，则整项反应不可用。
- **次数与边界：**每程一次；不减免伤害或强移，不拆剧情锁锚。

## 用途与反制

不依赖绳桥进攻，或先控住绳另一端。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

安全锚可拆后仍受推；桥上有人时反应不可支付。

## 获得与锻造

完成 `P05` 霜冠旧栈后，雪线工棚的同级研究池开放本件固定图纸。首次登记图纸后免费试制首件；研究池逐项选择，不随机抽取。领取以账号与装备ID幂等登记，重复确认只返回已有制作记录，不能出售重复生成的物件换材料。后续制作与重铸遵循成长文档的统一经济规则。本件来源是关卡完成后的工坊研究池，不声称关卡地面上存在一个未标坐标的宝箱。竞技同版本借用库提供同规格。

## 独立使用与组合

单件规则在散搭时完整生效。若被套装目录列入某同名系列，套装属性按独立套装规则和总预算结算，不改变本件条件、不增加第二个职业身份。未列入系列的物件没有隐含套装奖励。玩家端准确显示本件属性与发动规则，不自动公布跨装备构筑配方。
