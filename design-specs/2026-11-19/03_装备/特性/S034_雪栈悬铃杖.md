# S034　雪栈悬铃杖

| 字段 | 规格 |
|---|---|
| 装备ID | `S034` |
| 种类 | 特性装备 |
| 槽位 | `MH` |
| 器具类型 | 长杖 |
| 固定基础属性 | 生命+4、武力+3、护甲+4；其余属性+0 |
| 正向预算 | 生命4÷4 + 武力3÷1 + 护甲4÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 武器操作

- 双手，占主手和副手；副手必须空。
- 普攻取值为术力→法抗，P12，1 AP、0精力，距离1–3的一名可见敌人，直射，受矮掩体修正。使用后占本次主动伤害动作。
- 招牌「铺辉」为2 AP、2精力、CD2。距3内锁定十字5格，下一次自身激活开始结算P18、延时系数0.90，消耗结算激活的伤害动作；被强移离起手格或倒地取消。 基础读取术力→法抗，发动标签为咏唱。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 特性

铺辉可把落区十字中央的伤害删除，保留四臂P18；中央临时成为安全点，预告同步画空心，费用CD不变。

## 用途与应对

让前排站中心，敌人也可抢中心避爆。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

巨体若跨中心及一臂仍仅中一发，不因中心安全而整体免疫。
