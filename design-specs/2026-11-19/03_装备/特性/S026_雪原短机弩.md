# S026　雪原短机弩

| 字段 | 规格 |
|---|---|
| 装备ID | `S026` |
| 种类 | 特性装备 |
| 槽位 | `MH` |
| 器具类型 | 弩 |
| 固定基础属性 | 生命+4、术力+1、法抗+8；其余属性+0 |
| 正向预算 | 生命4÷4 + 术力1÷1 + 法抗8÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 武器操作

- 双手，占主手和副手；副手必须空。
- 普攻取值为武力→护甲，P12，1 AP、0精力，距离2–3的一名可见敌人，直射，受矮掩体修正。使用后占本次主动伤害动作。
- 招牌「钉射」为1 AP、2精力、CD2。单个距离2–3可见敌人P18、单格系数1.00，无额外定身；目标格上的可损木楔同时破坏。 基础读取武力→护甲，发动标签为武技。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 特性

钉射在自己前一次激活没有造成主动伤害时，可以把最短射程2改为1；P18降至12、单格系数1.00，CD仍2，必须在确认时选短射。

## 用途与应对

近身自保需提前空出伤害动作，连打没有优势。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

上一激活用工具造成伤害也会取消短射资格。
