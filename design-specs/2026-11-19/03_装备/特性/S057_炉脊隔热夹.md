# S057　断堤联作·炉脊隔热夹

| 字段 | 规格 |
|---|---|
| 装备ID | `S057` |
| 种类 | 特性装备 |
| 槽位 | `OH` |
| 器具类型 | 夹 |
| 固定基础属性 | 生命+4、武力+2、法抗+4；其余属性+0 |
| 正向预算 | 生命4÷4 + 武力2÷1 + 法抗4÷2 = 5；另按系列满足件数计套装奖励 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 持用

单手副手，须主手为空或单手器具。未写明的架盾、基础机关交互仍采用统一规则，外形不自动赋予额外防御或导电能力。

## 特性

对相邻已暴露的可携热工物件进行搬运交互时，允许忽略该物件定义的单次烫手伤害，额外耗1精力，每轮一次；不处理任务核心规则。

## 用途与应对

适合搬炉件，敌人攻击照常命中。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

普通火格通行伤害不因隔热夹消失。

## 获得与工坊

完成 `P01` 归湾渡口后，修葺台的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「定握距、固定外框并检查接点→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

## 联动边界

玩家界面显示本件自身说明、有效目标、实际费用和预览结果。开发检查同一机制对五族及各职业一致生效；任何跨职收益都需通过该角色当前属性、已选技能和本件实际操作形成，不按搭配名字触发。

## 系列与自由搭配

本件属于 **F12 断堤联作**，单独穿戴时保留全部上述基础属性和单件效果。不同ID计件，重复实例不重复计件，双手武器仅计一件。

- 装备本系列2件时，额外生命+4、护甲+2（此档新增2预算）。
- 装备本系列5件时，额外武力+1、护甲+2、法抗+2（此档新增3预算）。

各档累计；不足件数立即失去对应奖励。成员：S057, S107, S153, S178, S077。五件包含副手与工具，脱离可交互地形后可能不如散件。套装不自动改职业、取值、技能槽或形态次数。详见[系列与套装规则](../01_系列与套装规则.md)。
