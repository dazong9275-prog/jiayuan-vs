# S039　炉脊侧臂锤

| 字段 | 规格 |
|---|---|
| 装备ID | `S039` |
| 种类 | 特性装备 |
| 槽位 | `MH` |
| 器具类型 | 盾锤 |
| 固定基础属性 | 生命+4、术力+1、护甲+6、法抗+2；其余属性+0 |
| 正向预算 | 生命4÷4 + 术力1÷1 + 护甲6÷2 + 法抗2÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 武器操作

- 单手，占主手；可以搭配一件合法副手。
- 普攻取值为武力→护甲，P12，1 AP、0精力，距离1，四向相邻敌人一名。使用后占本次主动伤害动作。
- 招牌「压面」为1 AP、1精力、CD1。相邻单敌P12、单格系数1.00，命中后按方向推1格，受强移全局限制。 基础读取武力→护甲，发动标签为武技。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 特性

压面可指定与自己相邻但位于朝向左侧的一名敌人，仍朝相对本人向外推1格；P12降至8、费用不变。

## 用途与应对

控制侧面牺牲伤害，目标背后占用可使强移失败。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

目标在对角格不因左侧规则获得合法性。

## 获得与工坊

完成 `P07` 双河争闸后，合流测绘台的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「制柄、固定工作端并校直→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。
