# S002　低檐铜剑

| 字段 | 规格 |
|---|---|
| 装备ID | `S002` |
| 种类 | 特性装备 |
| 槽位 | `MH` |
| 器具类型 | 剑 |
| 固定基础属性 | 武力+1、术力+2、法抗+6；其余属性+0 |
| 正向预算 | 武力1÷1 + 术力2÷1 + 法抗6÷2 = 6 |

## 武器操作

- 单手，占主手；可以搭配一件合法副手。
- 普攻取值为武力→护甲，P12，1 AP、0精力，距离1，四向相邻敌人一名。使用后占本次主动伤害动作。
- 招牌「切线」为1 AP、1精力、CD1。指定前方横排最多2格内的敌人，P10，横排系数0.75；实墙截断，友军不受伤。 基础读取武力→护甲，发动标签为武技。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 特性

本人的切线若以可损坏铜制薄片为主目标，可在伤害替代模式下将其旋转90度而不损毁；1 AP、1精力、CD1，仍占主动伤害动作。只认地图提供的转轴。

## 用途与应对

用攻击动作调转反射板，离开转轴或先将板拆掉可消除收益。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

无转轴铜墙不能被此武器旋转，命令校验拒绝且不耗费。

## 获得与工坊

完成 `P02` 砺风牧道后，游牧锻台的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「制柄、固定工作端并校直→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。
