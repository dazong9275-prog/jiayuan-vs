# S139　泥根重围

| 字段 | 规格 |
|---|---|
| 装备ID | `S139` |
| 种类 | 特性装备 |
| 槽位 | `BD` |
| 固定基础属性 | 武力+1、护甲+10；其余属性+0 |
| 正向预算 | 武力1÷1 + 护甲10÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |

## 单件规则

站稳后可暂时增加压力板的承重读数。

## 发动与结算

- **时机与费用：**自身在压力板上花1AP、1精力压身。
- **结果：**该板把本人的重量读为2，至自身下次激活开始。
- **次数与边界：**只改变压力读数，仍1×1，不改变占点人数、伤害或携带；离板立即结束。

## 用途与反制

在下一次开关前推离或切断板的输出。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

板要求两份重量时可开，但两个相邻板不会都计入。
