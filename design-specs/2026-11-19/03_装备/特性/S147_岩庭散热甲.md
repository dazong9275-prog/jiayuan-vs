# S147　岩庭散热甲

| 字段 | 规格 |
|---|---|
| 装备ID | `S147` |
| 种类 | 特性装备 |
| 槽位 | `BD` |
| 固定基础属性 | 术力+3、护甲+2、法抗+4；其余属性+0 |
| 正向预算 | 术力3÷1 + 护甲2÷2 + 法抗4÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |
| 切换时机 | 营地与竞技备战；进入关卡或一场两程对局后锁定 |

## 单件规则

在同一激活先走后施术时，可以排掉一层油污。

## 发动与结算

- **时机与费用：**自身先完成普通步行、再完成咏唱主动，且仍有油污附着，付1精力。
- **结果：**移除自身油污，并在最后落格保留一格油迹至下一轮末。
- **次数与边界：**油迹按地图油标签参与交互，双方生效；每轮一次，不额外造成伤害。

## 用途与反制

用火威胁留下油迹的位置，或避免进入。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

无油污不能平地造油，清掉人物油污不会清掉原地所有油地形。
