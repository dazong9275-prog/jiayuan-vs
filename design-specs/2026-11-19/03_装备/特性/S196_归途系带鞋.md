# S196　归途系带鞋

| 字段 | 规格 |
|---|---|
| 装备ID | `S196` |
| 种类 | 特性装备 |
| 槽位 | `FT` |
| 固定基础属性 | 生命+16、武力+2；其余属性+0 |
| 正向预算 | 生命16÷4 + 武力2÷1 = 6 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |
| 切换时机 | 营地与竞技备战；进入关卡或一场两程对局后锁定 |

## 单件规则

第一次复归时，可以把脚边旧陷阱先标出来。

## 发动与结算

- **时机与费用：**本程首次复归激活开始，额外付1精力，选择距2一个本队已知敌陷阱。
- **结果：**向双方显示其精确格及剩余寿命，至本轮末；不会解除陷阱。
- **次数与边界：**每程一次；无已知陷阱则不能发动；复归仍只1AP且仅步行/架盾，标记不占AP。

## 用途与反制

放置另一陷阱，或利用已知陷阱限制路线。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

未知陷阱不能凭此探测，第二次复归不再次触发。

## 获得与锻造

完成 `P01` 归湾渡口后，修葺台的同级研究池开放本件固定图纸。首次登记图纸后免费试制首件；研究池逐项选择，不随机抽取。领取以账号与装备ID幂等登记，重复确认只返回已有制作记录，不能出售重复生成的物件换材料。后续制作与重铸遵循成长文档的统一经济规则。本件来源是关卡完成后的工坊研究池，不声称关卡地面上存在一个未标坐标的宝箱。竞技同版本借用库提供同规格。

单件规则在散搭时完整生效。若被套装目录列入某同名系列，套装属性按独立套装规则和总预算结算，不改变本件条件、不增加第二个职业身份。未列入系列的物件没有隐含套装奖励。玩家端准确显示本件属性与发动规则，不自动公布跨装备构筑配方。
