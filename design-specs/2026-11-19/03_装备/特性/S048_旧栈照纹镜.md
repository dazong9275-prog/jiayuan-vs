# S048　旧栈照纹镜

| 字段 | 规格 |
|---|---|
| 装备ID | `S048` |
| 种类 | 特性装备 |
| 槽位 | `OH` |
| 器具类型 | 镜 |
| 固定基础属性 | 武力+1、护甲+4、法抗+6；其余属性+0 |
| 正向预算 | 武力1÷1 + 护甲4÷2 + 法抗6÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 持用

单手副手，须主手为空或单手器具。未写明的架盾、基础机关交互仍采用统一规则，外形不自动赋予额外防御或导电能力。

## 特性

花1 AP、1精力照向距2可见的可读刻纹物件，揭示其已经定义的开关状态至本轮末，CD1；不显示敌人隐私配置或地图外区域。

## 用途与应对

帮助远读机关，近身交互能做同样事。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

无刻纹标签的物件不会收到额外状态信息。

## 获得与工坊

完成 `P08` 归湾长夜后，共建工坊的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「定握距、固定外框并检查接点→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。
