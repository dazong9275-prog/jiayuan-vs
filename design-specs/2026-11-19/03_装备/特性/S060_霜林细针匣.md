# S060　霜林细针匣

| 字段 | 规格 |
|---|---|
| 装备ID | `S060` |
| 种类 | 特性装备 |
| 槽位 | `OH` |
| 器具类型 | 匣 |
| 固定基础属性 | 生命+8、武力+1、法抗+6；其余属性+0 |
| 正向预算 | 生命8÷4 + 武力1÷1 + 法抗6÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 持用

单手副手，须主手为空或单手器具。未写明的架盾、基础机关交互仍采用统一规则，外形不自动赋予额外防御或导电能力。

## 特性

可花1 AP、1精力移除距1友军身上的一枚由地图陷阱施加的减步标记，CD2；不治疗、不解除沉默、不清敌方技能状态。

## 用途与应对

针对场景陷阱，在纯对拼图需换装。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

技能定身状态不能借地图清理解除。

## 获得与工坊

完成 `P04` 琥汀断堤后，汀岸细工坊的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「定握距、固定外框并检查接点→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。
