# S049　穗根滤光片

| 字段 | 规格 |
|---|---|
| 装备ID | `S049` |
| 种类 | 特性装备 |
| 槽位 | `OH` |
| 器具类型 | 镜 |
| 固定基础属性 | 生命+4、护甲+8、法抗+2；其余属性+0 |
| 正向预算 | 生命4÷4 + 护甲8÷2 + 法抗2÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 持用

单手副手，须主手为空或单手器具。未写明的架盾、基础机关交互仍采用统一规则，外形不自动赋予额外防御或导电能力。

## 特性

施放一个普通单目标护盾技时，可额外花1精力让其只防法伤，同时该盾数值增加4但上限16，持续时间不变，每轮一次。

## 用途与应对

面对物理会亏，混合攻击能绕。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

原盾14改为16而非18，物理命中不吸收。

## 获得与工坊

完成 `P01` 归湾渡口后，修葺台的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「定握距、固定外框并检查接点→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。
