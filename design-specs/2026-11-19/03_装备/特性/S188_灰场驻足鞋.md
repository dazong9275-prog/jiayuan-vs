# S188　灰场驻足鞋

| 字段 | 规格 |
|---|---|
| 装备ID | `S188` |
| 种类 | 特性装备 |
| 槽位 | `FT` |
| 固定基础属性 | 术力+1、护甲+6、法抗+4；其余属性+0 |
| 正向预算 | 术力1÷1 + 护甲6÷2 + 法抗4÷2 = 6 |
| 角色限制 | 五族、十职业均可装备，无职业或种族锁定 |
| 切换时机 | 营地与竞技备战；进入关卡或一场两程对局后锁定 |

## 单件规则

在器械旁停下时，可让操作杆暂时保持当前方向。

## 发动与结算

- **时机与费用：**普通步行结束四向邻接己方可转向器械，额外付1精力。
- **结果：**该器械朝向锁定至自身下一次激活开始，双方均不能旋转；攻击、拆除照常。
- **次数与边界：**每轮一次；不固定器械位置或耐久；只锁一个有朝向物件。

## 用途与反制

换射线、拆掉器械或等待锁定结束。

## 统一边界

基础架盾为1AP、0精力、8普通盾至下次自身激活开始。物品未说明的费用、射程、动作槽、施法条件与持续时间均沿用原动作。每棋每轮一次反应；物件次级事件不得继续触发任何物件或反应。盾同时最多16且取较高，治疗每目标每轮最多24，装备返能每棋每轮合计1，物件次级伤害每目标每轮合计8，强移每目标每轮一次且至多2格。无合法对象或条件未成立时拒绝并不扣本件费用。装备不能创建说明中未声明的地形；地物材质与可操作权限只读地图数据。

## 最小验收

锁定东向期间转向命令拒绝且无耗费；原地射击仍能执行。
