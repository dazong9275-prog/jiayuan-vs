# S033　黑炉纪行·炉脊凿星杖

| 字段 | 规格 |
|---|---|
| 装备ID | `S033` |
| 种类 | 特性装备 |
| 槽位 | `MH` |
| 器具类型 | 长杖 |
| 固定基础属性 | 生命+4、武力+1、护甲+2、法抗+4；其余属性+0 |
| 正向预算 | 生命4÷4 + 武力1÷1 + 护甲2÷2 + 法抗4÷2 = 5；另按系列满足件数计套装奖励 |
| 角色限制 | 五族、十职业均可装备，受武器动作所需器具限制 |
| 装备生效 | 营地或竞技备战时切换，局内锁定 |

## 武器操作

- 双手，占主手和副手；副手必须空。
- 普攻取值为术力→法抗，P12，1 AP、0精力，距离1–3的一名可见敌人，直射，受矮掩体修正。使用后占本次主动伤害动作。
- 招牌「铺辉」为2 AP、2精力、CD2。距3内锁定十字5格，下一次自身激活开始结算P18、延时系数0.90，消耗结算激活的伤害动作；被强移离起手格或倒地取消。 基础读取术力→法抗，发动标签为咏唱。
- 特性若写替代目标、改P或改格形，则只替换明确写出的部分。伤害及对象交互次数照统一规则。

## 特性

铺辉可把十字5格改成锁定单格P24的延时爆发，系数0.90；2 AP、2精力、CD2，仍公开一轮预告。该格有脆石地物时可损坏一个预置破损层。

## 用途与应对

高威力更易躲，搬动施术者可取消。

## 结算约束

本件只能改变上述明确操作。普通护盾取较高且总上限16；治疗每目标每轮24；精力返还每棋每轮合计1；物件次级伤害每目标每轮合计8。反应占用人物每轮一次反应，物件次级效果禁止再触发物件或反应。变形、强移、核心携带均服从统一规则；不满足条件时不产生额外收益。

## 最小验收

同格脆石和人物均存在时按地图对象顺序各结算一次，无穿地追加伤害。

## 获得与工坊

完成 `P01` 归湾渡口后，修葺台的同级研究列表永久开放本件。首次试制免费领取，所需制作记录是该关通关标记与本件ID。 工序按「制柄、固定工作端并校直→检查本件属性→确认领取」完成，一次确认即可，无现实计时。首次领取以角色账号和装备ID幂等登记，重复领取只能生成已有物件的替换副本，不能出售换资源。竞技借用库开放同规格。本件记录的来源是关卡研究池，不声称关卡地图上有一个未标坐标的独立宝箱。

玩家界面显示本件自身说明、有效目标、实际费用和预览结果。开发检查同一机制对五族及各职业一致生效；任何跨职收益都需通过该角色当前属性、已选技能和本件实际操作形成，不按搭配名字触发。

## 系列与自由搭配

本件属于 **F11 黑炉纪行**，单独穿戴时保留全部上述基础属性和单件效果。不同ID计件，重复实例不重复计件，双手武器仅计一件。

- 装备本系列2件时，额外武力+1、法抗+2（此档新增2预算）。
- 装备本系列5件时，额外生命+4、武力+1、术力+1（此档新增3预算）。

各档累计；不足件数立即失去对应奖励。成员：S033, S106, S130, S152, S197。分散属性不等于全能，五件占位并不能解决精力与行动不足。套装不自动改职业、取值、技能槽或形态次数。详见[系列与套装规则](../01_系列与套装规则.md)。
