# 平衡边界与验证计划

## 可确定的数学与待实测的体验

属性基线、公式、同名上限、事件时序和地图坐标属于实现合同；面板强弱、胜率、趣味性、绕行是否太长以及陌生人协作压力属于测试结果。本包的可达性检查只证明某个静态局面存在路线。敌方阻挡、伤害、实际资源、冷却和对手博弈会改变路线价值。

基准单目标普通攻击P12、攻20、对应防20时为floor(32×100/120)=26。防40时为22、防60时为20、防80时为17。高防增长仍提高存活，但不会让任何合法攻击自动归零；普通伤害最少0来自护盾真实吸收。最大合法攻60的P12攻击在防0时可达72。两次直接集火可超过最低合法满血，因此仅凭属性上限不足以保证前稿的「两击不能秒杀」。本版把这条改为需要通过开场接触距离、掩体、护盾和技能成本验证的首杀指标，禁止声称数值上已经证明。若测试发现满血角色在第一次自主激活前必死，地图和该技能组合不得进入排位版本。

## 建立可比较的局面

每个技能先在无装备基础角色上测单体、直线、四格、遮挡和同一目标多格命中。再加最小生命、最大单防、最高攻值、双手占槽、资源返还装备和接近有效预算14的九槽自选技栏。每种组合记录起点、轮序、AP、精力、CD、伤害、护盾、位移、次数账本与最终地图。被动/装备事件统一从主事件派生，次级事件不得再次产生次级事件。

伤害、治疗、护盾上限不是单品自己的额度。每棋全装备精力返还每轮1，每目标物件附伤每轮8，每目标治疗每轮24、总盾16。同目标敌方强移每轮一次至多2格。所有额外消耗必须在确认命令前预览，不可结算后临时追扣。激活过程死亡、复归、变形均不能刷新轮次账本。

## 需要直接阻断发布的行为

| 案例 | 检查法 | 合格结果 |
|---|---|---|
| 自伤、队友推拉、反复开阀回资源 | 以最小费用反复执行直到20轮 | 未出现无上限精力、额外AP、永久层数或重复目标分 |
| 反应打反应、两人各带返伤 | 一个主攻击引发双边被动 | 每棋反应次数唯一，次级事件不能继续传播 |
| 跨轮沉默 | 两名施术者错开CD与目标行动 | 解印或到期后两次完整自身激活免疫，禁止通过改来源刷新 |
| 2×2重复伤害 | 扇形覆盖巨人四格，附带一次物件伤害 | 同一主技能一次命中，附伤只记一次；四格不能计成四个人 |
| 护盾套娃 | 受击前盾、职业盾、物件盾同时满足 | 按统一优先顺序取有效盾，生命损失可由预览重现 |
| 换装和复归刷新 | 倒地、复归、重连、中途交换物品 | 场内药品/形态/每程次数保持，程间规定重置才刷新 |
| 灯芯位置穿越 | 将灯给巨体、跨障、击退到检查线、放下重捡 | 阶段只按持物者在检查区结束自主激活计一次，不能靠外缘占格或受推刷分 |
| 永久封路 | 两名巨体、两个器械、障碍放置组合 | 至少有可实际执行的撤退、拆除或改道机会；静态图连通不足以判合格 |
| 断线奖品翻倍 | 命令已提交但客户端未收到响应 | 重试返回同一结果，奖励主键不重复写入 |

## 胜率和体验指标

每张竞技图分别按1v1和2v2、技术段、装备库版本分层。配对实验交换双方选手所用攻守起点和行动序，至少记录100对用于初步诊断；人数不足时明确区间宽度。正式判定时使用足够窄的置信区间，先手/出生侧胜率目标47%–53%仅作方向，不凭一个总体50%结论判平衡。角色和职业出场率需要与流派、地图及搭档共现一起看，重复选择的唯一无代价部件优先调整。

逐局记录首次有效互动激活数、护送各阶段达成时间、放弃目标的待机比例、最高连控、首次自主行动前的死亡、伤害/护盾/治疗、有效推动、被迫改线、方案重配次数、投降与重连。双排记录队友预标成功转化、交接拒绝、是否长期轮到同一人旁观。不同贡献不能只用击杀评分代替。

发现冷门打法后安排盲测：另一队只看普通卡面和一次回放，指出可行动的反制；原队换一张地图并移去一个核心物件，尝试用另一个合法手段继续承担相同职责。若卡面无法推导实际结果，先修说明或实现；若只有某四件特定名称触发强大隐奖，删除该配方特判。

## 装备批次导入

先导入每槽2件普通和12件特性，再以每批20件开放研究。各批做效果类型覆盖和两两交互检查，涉及资源、控制、移动、体形的部件增加三件交互搜索。300件装备不需要穷举所有8槽组合，但应优先求出单目标爆发、移动可达、反应触发和持灯推进的上下界。数值修改同时标注受影响的职业、地图、存档与回放版本。

每件特性应改变一次选择，改变的可以是施术位置、预留精力、自己站前还是站后、先互动还是先出招。只有名字和正向数值不同、且所有条件相同的条目需要合并或重新设计。普通装备可使用不同分配作为教学样本，其独立意义是让玩家比较同预算的基础属性。
