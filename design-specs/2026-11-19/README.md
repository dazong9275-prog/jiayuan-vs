# 家园 · 完整机制与内容设计包

交付版本：2026-11-19。全部为Markdown设计规格；本包不含模型、人物图片、Word或可运行游戏。原有角色素材不在本包重复打包。数值用于开发原型，实机竞技平衡仍需验证。

本轮已纳入最新方向：传统职业有可靠完整的装备与技能选择；玩家可使用2件、3件、5件系列奖励，也可拿单件散搭；特殊打法通过装备、技能、属性与地形的关系由玩家研究，不自动授予预设隐藏职业。

## 已明确的产品假设

装备面板采用主手＋其余7槽，共8槽。1v1每人控制2棋；2v2每人控制1棋，双方总兵力都是2棋。竞技采用同一非对称地图的两程护送，两程交换队伍实际出生侧与任务，护送地理方向保持一致。剧情P01两人、P02起三人。以上是本稿用于落地规格的选择，后续改变须同步重验地图。
